# Media Tool Windows 便携版

1. 将整个压缩包解压到本地可写目录，例如 D:\MediaTool。不要直接在压缩包中运行。
2. 双击 Start-MediaTool.cmd。第一次启动会准备自带运行时，请等待控制台提示。
3. 浏览器自动打开 Media Tool。没有打开时，复制控制台中的本地网址到浏览器。
4. 导入视频/音频，首次识别勾选“允许下载模型”。默认发布包不包含模型，需要联网；下载后可离线使用。
5. 退出前先下载校对后的 TXT/SRT/视频，再回到启动窗口按 Ctrl+C，或双击 Stop-MediaTool.cmd。关闭浏览器页面不会取消后台任务。

无需安装 Miniforge、Conda、Python、Node、nvm 或 FFmpeg。支持 Windows 10/11 x64；不适用于 ARM Windows、macOS、Linux。建议使用较短的本地目录路径。

上传时可“取消上传”，识别及字幕生成期间可“取消处理”，视频导出可“取消导出”。取消模型下载/加载或正在执行的 GPU 步骤时，会真实显示正在等待安全返回；这些同步操作不能立即强行停止。后台完成清理后才能重新开始。取消新的识别或视频导出保留此前已完成的字幕。

## 文件存放

- models：模型缓存。首次下载后可保留，也可以从另一份便携包复制完整缓存。
- data：本次运行的上传媒体和导出临时文件，正常退出后清理 session 目录。
- logs：运行日志；启动错误优先看控制台，后台任务错误可查看 media-tool.log。
- runtime.zip：原始私有运行时，请保留。
- runtime：首次启动自动生成，不需用户安装。整包移到新目录后会从 runtime.zip 自动重新初始化，不清空 models。
- tools、web、backend：程序文件，请一起保留。

程序仅监听本机 127.0.0.1，默认端口 8765；端口占用会自动尝试后续端口。同一目录重复双击不会启动第二份。启动窗口应保持打开。

## CPU / GPU

无 NVIDIA 显卡时，选择 CPU + int8 和 H.264 CPU。NVIDIA GPU 所需 cuBLAS/cuDNN 库已经随运行时包含，但显卡驱动仍由 Windows/设备管理维护；GPU 检测或识别失败时可用 CPU。没有捆绑显卡驱动，也不会修改系统 PATH。

默认包不包含模型。若需要完全离线，制包方需先下载需要的模型并在构建时加入 models；首次选择的模型必须与离线缓存相符。

重启不恢复内存中的识别任务或尚未导出的编辑结果。应用运行期间不要移动目录或清理 runtime/data。移动前正常退出。

可双击启动器正常使用；技术检查可在该目录 PowerShell 执行 `./Start-MediaTool.cmd --check`，只检测运行时和硬件，不下载模型。
