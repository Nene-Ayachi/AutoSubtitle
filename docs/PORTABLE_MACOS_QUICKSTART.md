# Media Tool · macOS Apple Silicon 便携版

适用于 Apple Silicon（M 系列）Mac，macOS 14 或更新版本。不支持 Intel Mac/Rosetta。

1. 完整解压 ZIP 到有写权限的本地目录，不能直接在压缩包内运行。
2. 首次双击 `首次信任并启动.command`。确认显示的目录是刚解压的软件包，核实来源后输入大写 `TRUST` 并回车；脚本仅解除当前包的隔离标记，然后自动启动。其他输入、直接回车或关闭窗口会取消，不修改标记、不启动程序。以后直接双击 `Start-MediaTool.command`。无需安装 Python、Node、Homebrew，也无需运行 Setup。
3. 首次识别选择模型并勾选允许下载；之后相同模型可离线使用。建议先选 small / 自动设备 / 自动精度。自动优先使用 Metal GPU，不可用时选择 CPU。
4. 导出字幕/视频后，双击 `Stop-MediaTool.command`，或在启动的终端按 Ctrl+C。关闭浏览器不会停止服务。

程序只监听 127.0.0.1。模型、工作文件和日志分别保存在包内 models、data、logs。退出后可以移动整个文件夹，不能只搬启动脚本。首次下载模型仍需网络和额外磁盘空间，默认 ZIP 不含模型。

此包未经过 Apple Developer ID 签名及公证。如果 macOS 拦截首次入口，先尝试打开它，再到“系统设置 → 隐私与安全性”中允许该入口打开。随后在终端确认本地信任。这个流程不能保证系统严格只弹一次，也不能绕过恶意软件检测或组织管理策略。

信任脚本使用系统自带工具，不先运行包内 Python；不关闭 Gatekeeper、不使用 sudo、不清除其他扩展属性、不沿符号链接处理包外文件。只处理当前完整软件包，不会修改 ZIP 或其他已解压副本。重新下载、换版本或新增带隔离标记的组件后，应重新核实来源并运行首次入口。脚本报错时不启动程序，已处理的部分文件可能已经解除隔离。

如果启动失败，保留终端错误及 logs/media-tool.log。请勿删除 runtime 内的许可证或移动单个运行库。不能使用 Windows 版运行时替换 runtime。

## 模型下载与代理

包内包含 HTTP/SOCKS5 代理支持。下载库默认读取 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`（包括小写形式）及 `NO_PROXY`；没有代理环境配置时，会尝试读取 macOS 系统的静态 HTTP/HTTPS 代理。终端环境配置可能优先于系统设置，不等同于浏览器自动执行 PAC 脚本。勾选“允许下载”只控制是否允许获取模型，不会开启或切换代理。修改代理设置后请停止并重新启动应用。
